# WorkLog releases

Public downloads, the [Sparkle](https://sparkle-project.org) update feed and the Claude plugin for **WorkLog**,
a macOS menu-bar app by Antonius Greiner that records your working day privately on your Mac and books it with
Claude (`/timebooking`).

- **Install the app:** download [WorkLog.zip](https://github.com/committopush/worklog-releases/releases/latest/download/WorkLog.zip),
  unzip, move WorkLog to Applications and open it. Updates arrive automatically.
- **Add the Claude plugin:** in Claude Desktop, Customize → Plugins → Add → Add marketplace →
  `committopush/worklog-releases`, then add **WorkLog**. WorkLog's setup window walks you through it.

Requires macOS 14 or later and the Claude desktop app. Signed with Developer ID and notarized by Apple. Source
code is private.
