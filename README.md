# WorkLog releases

Public downloads and the [Sparkle](https://sparkle-project.org) update feed for **WorkLog**, a macOS menu-bar app
by Antonius Greiner that records your working day privately on your Mac and books it with Claude (`/timebooking`).

- **Install the app:** download [WorkLog.zip](https://github.com/committopush/worklog-releases/releases/latest/download/WorkLog.zip),
  unzip, move WorkLog to Applications and open it. Updates arrive automatically.
- **Claude:** WorkLog's setup window installs the
  [WorkLog extension](https://github.com/committopush/worklog-releases/releases/latest/download/WorkLog.mcpb) and
  walks you through adding the `/timebooking` skill.

Requires macOS 14 or later and the Claude desktop app. Signed with Developer ID and notarized by Apple. Source
code is private.
