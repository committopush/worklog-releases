# WorkLog releases

Public downloads and the [Sparkle](https://sparkle-project.org) update feed for **WorkLog**, a macOS menu-bar
app that records your working day privately and books it with Claude (`/timebooking`).

- **Install:** download [WorkLog.zip](https://github.com/committopush/worklog-releases/releases/latest/download/WorkLog.zip),
  unzip, move WorkLog to Applications and open it. Updates arrive automatically.
- **Claude Desktop extension:** [WorkLog.mcpb](https://github.com/committopush/worklog-releases/releases/latest/download/WorkLog.mcpb)
  (the app's setup window installs it for you).

Requires macOS 14 or later. Signed with Developer ID and notarized by Apple. Source code is private.
